# Кнопки поделиться

В этом билде есть кнопки:

- Telegram
- VK
- MAX
- Скопировать ссылку

Важно по MAX: отдельной стабильной web-share ссылки для MAX я не нашёл. Поэтому кнопка MAX использует системное меню `navigator.share`.
На телефоне, если MAX установлен, он должен появиться среди вариантов отправки. Если браузер не поддерживает системный share, кнопка просто копирует ссылку.
