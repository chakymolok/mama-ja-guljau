# Правка главной

- Карточка свежего выпуска стоит справа от hero-текста, в зоне, где раньше были декоративные картинки.
- Левый текст обёрнут в `.hero-copy`, карточка является отдельной правой колонкой.
- На мобильной версии hero-карточка полностью скрыта.
- На мобильной версии после hero-текста дальше идёт обычный свежий дайджест.
- Мобильные блоки «Что внутри» и «Рубрики проекта» скрыты.
