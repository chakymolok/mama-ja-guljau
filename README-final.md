# Мама, я гуляю - финальный тестовый билд

Внутри:

- `index.html` - главная с одним тестовым выпуском №009.
- `style.css` - общие стили.
- `script.js` - мобильная навигация, копирование ссылки, счётчик прочтений.
- `assets/` - локальные картинки.
- `digests/2026-05-01/index.html` - страница выпуска.
- `api/views.js` - API для счётчика прочтений на Vercel.

## Что обновлено

- На главной оставлен только один тестовый выпуск.
- Страница выпуска сверстана как журнальная статья.
- Реальные картинки лежат локально в `assets`.
- Добавлены кнопки шера: Telegram, VK, WhatsApp, копирование ссылки.
- Добавлен счётчик прочтений.
- На мобильной версии есть плавающая кнопка навигации.
- Токены Upstash в код не добавлены. Их надо хранить только в Vercel Environment Variables.

## Vercel Environment Variables

Добавить в Vercel:

```text
UPSTASH_REDIS_REST_URL
UPSTASH_REDIS_REST_TOKEN
```

После добавления переменных сделать Redeploy.
