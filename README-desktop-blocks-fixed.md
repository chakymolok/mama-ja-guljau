# Исправление блоков на десктопе

Возвращены блоки «Что внутри» и «Рубрики проекта» на десктопе.

Логика теперь такая:

- desktop/tablet от 761px: блоки показываются;
- mobile до 760px: блоки скрываются;
- hero-фото справа сохраняется только на десктопе;
- на мобильной фото скрыто, чтобы сразу шёл свежий дайджест.
